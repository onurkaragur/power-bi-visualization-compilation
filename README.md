# 📊 Power BI Visualization Compilation

This repository includes my Power BI dashboard projects created from real-world sales datasets. Each `.pbix` file demonstrates how raw data can be turned into meaningful, interactive business insights.

---

## 🔹 1) Plant Sales Portfolio Dashboard
- **File**: `1)Plant_Sales_Porfolio_Project.pbix`
- **Data Source**: `1)Plant_DTS.xls`
- **Description**: Visualizes sales performance by product, region, and time. Includes category breakdowns and seasonal trends.

---

## 🔹 2) Pizza Sales Dashboard
- **File**: `2)pizza_sales_visualization.pbix`
- **Data Source**: `2)pizza_sales.csv`
- **Description**: Highlights top-selling pizzas, sales by size, peak ordering times, and monthly trends.
