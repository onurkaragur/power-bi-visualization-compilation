# 📊 Power BI Visualization Compilation

This repository includes my Power BI dashboard projects created from real-world sales datasets. Each `.pbix` file demonstrates how raw data can be turned into meaningful, interactive business insights.

---

## 🔹 1) Plant Sales Portfolio Dashboard
- **File**: `1)Plant_Sales_Porfolio_Project.pbix`
- **Data Source**: `1)Plant_DTS.xls`
- **Description**: Visualizes gross profit performance in 2023 across countries and product types. Features include monthly profit trends, category-based analysis, account profitability distribution, and a treemap highlighting top-performing countries.

---

## 🔹 2) Pizza Sales Dashboard
- **File**: `2)pizza_sales_visualization.pbix`
- **Data Source**: `2)pizza_sales.csv`
- **Description**: Analyzes pizza sales between Jan 15 and Dec 15. Highlights include total revenue, order volume, daily and monthly sales patterns, size/category breakdowns, and best-selling pizzas by revenue and volume.
